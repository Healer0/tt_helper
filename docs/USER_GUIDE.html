微信小游戏图文操作手册

先框选，再开启监测，最后启动钓鱼。监测和自动操作是两个步骤。

快速开始界面总览框选与点击位置开始与暂停常用设置问题排查

01 / 第一次使用

  1. 完整解压便携包。保留 app、runtime、source 和许可文件。无需安装Python，双击 启动钓鱼助手.bat。
  2. 在PC版微信中打开小游戏。在助手顶部选择实际游戏窗口；没有出现时点击“刷新”。
  3. 框选并配置点击位置。点击“2. 框选完整游戏画面”，3秒内切回游戏。完成选区后调整X/Y，让十字线和随机圆圈都落在按钮内。
  4. 点击“3. 应用设置并开启监测”。设置在这一步保存，此时尚未自动钓鱼。
  5. 点击“4. 3秒后启动钓鱼”，并在3秒内切回游戏。也可直接切回游戏按默认 F8。顶部显示“自动点击 · 运行中”后才发送点击。
“仅观察，不发送输入”默认不勾选；每次打开软件仍保持暂停。若希望先手动核对识别，可主动勾选“仅观察”。

02 / 新版界面在哪里操作

顶部：目标与当前状态

第1步选择微信小游戏窗口。“尚未监测”“仅监测”“自动点击”“已暂停”用于区分程序当前行为。

中部：框选、坐标与选项

“查看框选示例”说明完整游戏范围。“钓鱼选项”提供观察开关、点击坐标、随机半径、截图频率及次数／时长限制。

第3步与第4步

第3步保存设置并开启识别；第4步或F8才启动钓鱼。第4步显示“启动观察”时，说明仍勾选了仅观察。

暂停／取消启动与停止监测

暂停用于取消当前操作和启动倒计时；停止监测用于结束后台识别、解锁设置，修改后重新点第3步。

图文操作手册

顶部右侧按钮可打开本手册；便携包根目录也可以直接双击本HTML文件。

03 / 框选完整画面，放准点击位置

  1. 点击第2步后，助手暂时收起；3秒内将目标游戏置于前台。
  2. 在截图中拖选完整竖屏游戏区域，点击“确认选区”。
  3. 打开预览，核对画面完整、边界正确。
  4. 调整点击X/Y。X从左到右为0～1，Y从上到下为0～1。
默认X＝0.5、Y＝0.5位于画面中央，需要调整。可以先尝试X＝0.5、Y＝0.86，再以预览为准。整个黄色圆圈应处于下钩、拉钩和结算按钮共同可点击的位置。

随机偏移默认1.5%，表示框选画面短边的1.5%。可设置0～5%，填0关闭随机偏移。圆圈超出按钮时，应调整基准或减小半径。

改变游戏窗口大小后先停止监测，再重新框选。仅移动窗口时会跟随位置；选区复用前仍需核对预览。

04 / 开始、暂停与修改设置

想做什么操作预期结果
开始自动钓鱼取消仅观察，点第3步，再点第4步并切回游戏；或在游戏前台按F8。显示“自动点击 · 运行中”。
只看识别结果停止监测，勾选仅观察，重新点第3步并启动观察。更新识别状态，不发送点击。
暂停或取消倒计时点击“暂停／取消启动”，或按当前紧急暂停键，默认F9。取消待启动和待执行操作，明确启动后才恢复。
修改坐标、半径或其他设置先点“停止监测”，修改后重新点第3步。设置解锁；第3步保存并应用新值。
切回游戏继续游戏置于前台后按F8。从当前画面重新开始；建议从准备下钩界面启动。
点击助手、浏览器或其他窗口会让游戏失焦并暂停。返回游戏后需要明确重新启动。打开本手册也会先暂停。

快捷键以界面显示为准。若修改过F8／F9／F10，请使用保存后的实际快捷键。

05 / 常用设置

项目默认／用法
不停钓默认开启，会忽略次数和分钟上限。初次试运行可关闭，设置最多2次、最长2分钟；时长到达时暂停，次数达到后不再下钩。
截图频率每6个基准帧截图一次，目标约10次／秒。值越大采样越慢；卡顿时可调大。
鼠标点击按住默认30毫秒；按下后会释放，不是持续长按。
结果页等待默认3秒，之后根据新画面继续重试关闭结算。调整位置时需兼顾结算按钮。
未知画面／黄条等待默认60／120秒，填0关闭相应自动超时；遇到暂停先查看顶部原因。
速度与校准未勾校准时使用本机已保存速度，缺少时用参考值。勾选“本次校准速度”后稳定结果才保存；样本不足保留原值。
录制／截图F10显式保存截图；录制页可录制15秒手动操作，期间自动点击暂停。

06 / 为什么没有开始钓鱼

看到的现象处理办法
“仅监测 · 尚未启动钓鱼”第3步只开启监测。还需点击第4步并切回游戏，或在游戏前台按F8。
“只观察，不发送输入”停止监测，取消“仅观察”，重新应用设置并启动。旧配置可能保留了此前保存的观察选择。
显示“下钩一次”，实际次数仍是0观察模式会显示拟议动作但不执行；同时检查游戏焦点和顶部运行状态。
十字线在水面，点击没有效果停止监测，修改X/Y并核对预览。默认中央通常不是按钮位置。
开始后马上暂停查看顶部原因；确认3秒倒计时结束时游戏在前台，窗口尺寸未改变。
次数／分钟框是灰色不停钓开启时这两项不生效。关闭不停钓；若设置仍锁定，先停止监测。
点击没有反应或结算不关闭确认整个随机范围都位于按钮内、画面无遮挡，助手与微信权限级别一致。
无法启动便携版完整解压后运行“检查运行环境.bat”。启动异常记录位于data/logs/startup.log。

本机设置保存在data/config.json，完成的速度校准保存在data/speed_profile.json。正常钓鱼不自动写轨迹、截图或诊断ZIP。分享材料前清除昵称、账号及私人路径。
