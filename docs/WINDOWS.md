# Windows免安装便携版

## 普通用户

在项目的GitHub Releases中选择 `tt_fish-版本号-Windows-x64.zip`，完整解压，双击 `启动钓鱼助手.bat`。下载页是否已有对应版本，以项目实际发布为准。不要下载GitHub自动生成的Source code ZIP来代替便携包。

适用64位Windows 10／11上的PC版微信小游戏。包中带有独立CPython、Tcl/Tk、NumPy、OpenCV、Pillow和MSS；无需安装Python、Anaconda、PyCharm或额外运行pip，首次启动也不下载组件。微信和小游戏需自行准备。程序不会修改系统Python、注册表或PATH。

根目录的 `app/` 只保存必需的`.pyc`字节码、模板和框选示例，测试、构建脚本及开发文档已移出。`source/tt_fish-版本号-source.zip`保存完整对应源码、测试、文档和构建脚本，解压即可查看README或修改源码；分发时保留此归档及根目录LICENSE、NOTICE.md。字节码可被分析，不提供强加密或防逆向保证。

`runtime/`保存独立运行环境，`data/`在运行后保存本机设置和显式保存的数据。启动器使用随包Python隔离运行`app/desktop.pyc`，不读取用户安装的Python包和PYTHONPATH；无需用户安装Python，不要替换随包解释器或用其他版本解释器运行字节码。

解压到当前账户可写的位置，不要放在压缩包预览窗口、只读盘或需要提权才能写入的系统目录。同一个数据目录重复启动会提示切换到已打开的窗口。不同文件夹中的独立副本仍应避免同时控制同一游戏窗口。

初次使用需要选择微信游戏窗口、框选完整游戏区域、设置点击基准及随机半径，再应用设置并明确启动钓鱼。“仅观察”默认不勾选，需要先核对识别时可主动开启；软件启动时仍保持暂停。操作步骤见 [图文操作手册](USER_GUIDE.html) 或 [README](../README.md)。便携包根目录附有内嵌截图的“图文操作手册.html”，可离线查看。

## 更新与排查

- 更新：微信设置可随旧包的 `data/` 迁移。从源码版迁移时，把微信 `config.json` 放到便携包的 `data/`。旧其他环境或空格输入设置会报错，先备份并移除旧配置后重新设置；保留旧数据备份。
- 无法打开：双击 `检查运行环境.bat`，保留显示的错误；启动错误另写入 `data/logs/startup.log`。不要公开未经检查的错误日志。
- 文件被拦截或缺失：核对是否来自项目发布页、校验值是否一致，再按系统提示处理；不要以关闭安全软件作为常规步骤。
- 权限不一致：仅当微信以管理员身份运行时，才考虑以相同权限运行助手。
- 分享：发布构建得到的原始ZIP，不要重新压缩自己已经使用过的便携目录。

## 维护者重新生成

仓库根目录运行：

```bash
python build_windows.py
```

构建需在64位Windows运行，组装入口仅需本机Python 3.10以上标准库。首次构建从固定清单下载运行环境和依赖，逐项检查SHA-256；之后复用`.build-cache/`。运行代码由随包Python 3.12编译，不能用本机其他版本替代。全部文件编译成功后才移除构建临时目录中的`.py`，项目源文件保留不变。完整源码另附归档，构建不读取本机配置、日志或截图。

输出在 `dist/tt_fish-版本号-Windows-x64.zip`。构建验证无源码模块导入，再用随包解释器运行字节码环境检查，核对Tk、ImageTk、模板、录像编解码和显示器接口；该检查不截图、不发送输入。发布前仍需检查界面、框选、暂停与真实微信小游戏操作。

在GitHub上传源码后，也可进入 **Actions → Windows portable → Run workflow**。工作流在Windows机器上构建、检查，成功后提供可下载的构建产物。下载后将便携ZIP手动添加到GitHub Release；工作流不会自动发布版本。仓库须包含 `.github/workflows/windows-portable.yml`，不要漏传以点开头的目录。

`packaging/windows-runtime.lock.json` 固定依赖版本、来源和哈希。更新依赖时要同时核对Windows x64／Python 3.12兼容性及许可，验证实际下载后再更新清单；不要只改版本字符串。当前锁定包没有wheel的额外`.data`安装目录；新增此类依赖须先扩展并测试构建规则。

本项目使用独立运行环境目录实现免安装。请一起分发入口、app、runtime、source及许可文件。源码与运行文件各自采用明确清单，个人数据不进入成品；第三方二进制保留其上游许可，版本与下载来源记录在`DEPENDENCIES.json`。精简主要减少app文件数量；运行环境占据主要体积，另附源码后总包体不保证缩小。
