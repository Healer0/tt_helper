# 开发与验证

## 结构

- `main.py`：Tkinter界面、窗口选区、设置与预览开关。
- `fisher/vision.py`：图像归一化、颜色与局部模板识别。
- `fisher/controller.py`：钓鱼阶段、计数限制、结果重试和动作提交。
- `fisher/phase.py`：比例坐标、三角波运动相位、双向到达时间和同趟去重。
- `fisher/runtime.py`：固定频率截图、可取消的独立按键期限、控制命令和输入协调。
- `fisher/scheduling.py`：截图节奏与快捷键边沿。
- `fisher/speed.py`：参考速度、显式稳健校准和本机参数保存。
- `fisher/contact.py`：共享的有界延迟补偿及历史策略对照实现。
- `fisher/wechat.py`：微信进程白名单、游戏窗口筛选与选区归属校验。
- `fisher/windows.py`：窗口坐标、微信前台检查、鼠标点击和释放。
- `fisher/config.py`：配置校验、迁移及原子保存。
- `fisher/packaging.py`：公开文件清单和ZIP完整性检查。
- `desktop.py`、`build_windows.py`：可选便携启动与构建工具。

源码运行从`main.py`开始，仅支持Windows上的微信小游戏，正式界面固定使用`phase`策略。历史`contact`和`center`是内部算法回归对照，不提供其他运行平台或键盘输入入口。

`ROOT`用于静态资源，`DATA_ROOT`用于本机设置。新增公开文件时同步`PUBLIC_FILES`，不得将本机配置、诊断数据或整个截图目录加入清单。

## 决策与输入

控制器只提出动作，成功调用系统输入后才`commit()`。相位策略的未来HIT进入唯一的待执行槽；每张新图替换旧计划，未知画面或非判定阶段取消计划。循环在截图间隔内也处理按键期限，不使用等待数秒的阻塞调用。靠近期限时暂缓截图，先处理输入。

相位计划不能套用历史策略的80/120毫秒帧龄限制；它的预测范围由当前阶段和下一次观测约束。配置的暂停键、固定的Esc、失焦、窗口变化和退出仍取消输入。输入后保留运动相位；同趟锁定在离开目标后解除，目标变化可启动下一轮。

结果页的record和claim样式共用一段等待/重试流程。首次确认后等待，后续约每秒重试；未确认或离开结果页停止关闭动作。不可因为绿色按钮就把初始钓鱼界面当作开心收下。

`TRIAL_BUILD=False`为正式构建，不创建轨迹记录器或会话日志，不在暂停时导出ZIP。历史诊断模块只作为显式开发工具和回归依赖保留。手动回放与测试输出不属于正常钓鱼运行路径。

时序算法和边界见[算法说明](ALGORITHM.md)。当前模型假设匀速，不把长时间游戏停顿当作已解决问题；低频截图下不应宣称任意方向和变速都可唯一推断。

## 验证

```bash
python selfcheck.py
python replay.py
python build_release.py
```

自检不发送系统按键。`test_phase.py`包含模拟完整Runtime循环：分别以100毫秒和500毫秒采样，在两次截图之间执行HIT；验证左右折返、窄条、多轮目标、归一化缩放、暂停/失焦/未知/尺寸变化取消，以及校准不加密截图、不生成自动运行数据。旧策略、结算、截图预算、快捷键、输入释放、隐私及打包边界继续回归。

2026-10-23 微信专用精简版的 `python selfcheck.py` 共200项全部通过，`python -m unittest tools.poc.test_poc` 共14项全部通过，不发送系统输入。测试覆盖鼠标Runtime仿真、进程限定、配置拒绝、输入释放与重试；新增运行清单排除开发和私有文件、无源码字节码运行、解释器版本不匹配拒绝以及编译失败保留源文件检查。

收敛前的微信实机截图、限次闭环及校准保存证据保留在开发仓库的 `docs/HANDOVER.md`（不随发布包分发）。当前版完整GUI流程、2/5/8分钟分级稳定性及不同游戏窗口尺寸仍待验收。其他DPI、多屏、设备和微信版本环境、物理Esc实测按用户要求暂缓。

测试素材使用必要的局部游戏控件与脱敏历史框选示例。合成轨迹和录像回放不能证明实际游戏成功率，仍应区别离线检查与微信原生窗口实测。

配置版本10默认观察、点击、0.9秒动作间隔及1.5%随机半径，不再保存环境选择、输入方式、截图后端和空格按住时长。旧微信配置保留明确设置，移除废弃字段；其他环境或空格输入配置明确拒绝，原文件不在加载时改写。来源不明或越界选区会清除，合法微信选区按客户区尺寸复用，选区标记为`platform=wechat`。显式校准开关只对本次监测有效。速度文件仅允许比例与统计字段，不保存原始轨迹或窗口信息。

实时截图固定为mss，`Runtime.dispatch()`仅分派`Windows.click_at()`。窗口枚举和前台检查通过微信进程白名单确认归属，标题包含微信不足以接受其他进程；不提供其他窗口回退。`Windows.release()`仅释放本程序已按下的鼠标键，抬起失败后保留所有权供清理时重试。Win32 INPUT union中的键盘结构用于ABI布局，不存在键盘事件注入实现。

提交前执行自检与公开打包，检查源码清单、示例配置和图像中没有本机隐私。分发遵守LICENSE并保留第三方素材声明。可选便携构建见[WINDOWS.md](WINDOWS.md)。

便携构建使用`PORTABLE_FILES`运行清单和`PUBLIC_FILES`完整源码清单。运行目录不含测试、构建及诊断导出模块；Runtime仅在显式测试构建分支加载TrialRecorder。随包Python将运行源文件编译为同目录`.pyc`，相对文件名写入字节码，禁止用其他Python小版本代编译。启动及环境检查入口均为`app/desktop.pyc`；原项目源码和单独源码包继续保留`.py`，便携包完整源码另附于`source/`归档。

随机坐标在 `Windows.click_at()` 内生成，按 crop 短边计算圆形像素半径，拒绝基准点、上一落点及越界候选；抽样次数有界，失败时选择有效邻点。坐标查询和随机抽样后再次检查时效、焦点及取消状态。Runtime 只传入半径，不改变调度；预览圆圈表示允许的偏移范围。
